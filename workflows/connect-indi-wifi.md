# Connect Indi Wi-Fi

Use this procedure to connect Indi Wi-Fi to your site network.

## 1. Prepare the terminal

Record the terminal identity from its label. Confirm that the Basestation is
online. Confirm that the site Wi-Fi reaches the terminal location.

## 2. Apply power

Connect the specified DC power supply. Wait for the terminal to start. A terminal
without a saved network shows its temporary setup network.

## 3. Join the setup network

Use a phone or laptop to join the setup network shown on the terminal label.
Open the setup page. Enter the site Wi-Fi name and password. Submit the request.

## 4. Confirm the network connection

The temporary network closes after a successful connection. If it returns, open
the setup page again and read the displayed network error before you retry.

## 5. Complete commissioning

Open Devices on the Basestation. Complete [Commission a Terminal](commission-a-terminal.md).
Confirm that the terminal reports data before you use a control interface.
