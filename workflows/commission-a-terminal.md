# Commission a Terminal

Commissioning connects a physical terminal to the correct product profile, site,
and operating workflow.

## 1. Record the terminal identity

Read the identity from the terminal label. Use the identity for that terminal
only. Do not reuse an identity from another terminal.

## 2. Confirm the product and profile

Open Devices on the Basestation. Select the correct product and approved hardware
profile. A hardware profile for another product can give incorrect readings or
unsafe output behavior.

## 3. Set the site context

Set the site, location, and installation notes. Add the terminal to the asset
group that its workflow uses. Some Skills do not receive data from ungrouped
terminals.

## 4. Bring the terminal online

Complete the correct network procedure:

- [Connect Indi Wi-Fi](connect-indi-wifi.md)
- [Connect Indi LoRa or Agri](connect-lora-terminal.md)

## 5. Verify the terminal

Confirm that the terminal reports data. Check each connected channel for a
plausible value. Test a control interface only when the connected equipment is
safe to operate.

## If commissioning stops

Check power, terminal identity, product profile, network coverage, and asset
group membership. Record the terminal identity and the observed condition before
you contact Modulink support.
