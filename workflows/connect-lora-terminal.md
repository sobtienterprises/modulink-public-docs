# Connect Indi LoRa or Agri

Use this procedure for Indi LoRa, Indi LoRa (Legacy), and Agri terminals.

## 1. Confirm the product

Read the label and installation record. Select the procedure and hardware profile
for that exact product. Indi LoRa, Indi LoRa (Legacy), and Agri are different
products.

## 2. Prepare the site

Confirm that the Basestation and LoRaWAN service are online. Confirm radio
coverage at the terminal location. For Indi LoRa, confirm the specified line
power. For Agri, install the specified battery pack.

## 3. Register the terminal

Use the identity supplied with the terminal. Register it through the approved
Basestation workflow. Device keys are managed by Modulink. Do not copy keys
between terminals.

## 4. Wait for the first report

Apply power. The terminal joins the LoRaWAN network and sends a report. Open
Devices on the Basestation. Confirm that the terminal appears and reports data.

## 5. Commission the terminal

Complete [Commission a Terminal](commission-a-terminal.md). Then configure the
installed instruments and supported outputs.
