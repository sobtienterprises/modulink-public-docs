# Set Up a Basestation

Set up the Modulink Basestation before you connect terminals.

## 1. Connect power and network

Connect the Basestation to its specified power supply. Connect it to your site
network by Ethernet or Wi-Fi. Ethernet is preferred where it is available.

## 2. Confirm the site network

Use a computer on the same network. Open the Basestation address in a browser.
Many installations use `https://modulink.local`. If that address does not work,
ask the site network owner for the Basestation address.

## 3. Sign in and secure access

Sign in with the account supplied for your installation. Change any temporary
password. Create individual accounts for users who need access. Do not share an
administrator account.

## 4. Check the system

Open Dashboard and Devices. Confirm that the Basestation is online before you
commission a terminal.
