# Modulink Documentation

Use this site to plan, install, and operate a Modulink system. Modulink keeps
monitoring and control on your site.

## Products

| Product | Connection | Use |
| --- | --- | --- |
| [Modulink Basestation](hardware/basestation.md) | Site network | Runs dashboards, alerts, history, and user access. |
| [Indi Wi-Fi](hardware/indi-wifi.md) | Wi-Fi | Connects industrial instruments and compatible control interfaces. |
| [Indi LoRa](hardware/indi-lora.md) | LoRaWAN | Connects line-powered industrial equipment at low data rates. |
| [Agri](hardware/agri.md) | LoRaWAN | Monitors soil conditions and controls one latching irrigation valve. |
